# Рыцарь против Зомби (Knight vs Zombies)

Полноценная 8-битная экшен-выживалка на **Python** с использованием **Pygame** (`pygame-ce`), вдохновленная веб-версией игры и классическими арена-рогаликами.

---

## 🎮 Особенности игры

- **Полноценное главное меню и экран выбора класса**:
  - Анимированный фон с частицами пепла и огня, художественный баннер.
  - **Выбор класса при старте «Новая игра»**:
    - Интерактивные карточки 4 классов с характеристиками, аватарками, иконками и описанием всех 4 способностей.
    - Быстрый переход в бой выбранным героем.
  - **Продолжить игру** — автоматическая загрузка сохраненного забега (класс героя, волна, счет, HP, навыки).
  - **Прокачка лагеря (Мета-прогрессия)** — магазин улучшений за собранные души зомби:
    - Индивидуальная прокачка для каждого из 4 героев (Скорость, Здоровье, Урон).
    - При полной прокачке открываются уникальные **Мастерства**:
      - 🛡️ **Рыцарь**: *Отбивание пуль* — взмахи меча разрушают вражеские кислотные снаряды.
      - 🏹 **Лучник**: *Сверхзвуковые стрелы* — скорость полета стрел увеличена на +50%.
      - 🔮 **Маг**: *Сферы Эгиды* — 3 вращающихся защитных шара поглощают одну атаку врага и перезаряжаются 15 сек.
      - 💀 **Призыватель**: *Призыв Исполина* — каждый 10-й скелет становится колоссом с удвоенным здоровьем и уроном.
  - **Статистика и рекорды** — отслеживание рекорда очков, максимальной волны, общего числа убийств, сыгранных матчей и казны душ.
  - **Настройки** — переключение звука, тряски экрана (Screen Shake) и полноэкранного режима (F11).
  - **Руководство по управлению** — отдельные интерактивные вкладки для клавиатуры/мыши и геймпада / Steam Deck.
- **4 Уникальных Класса Персонажей**:
  1. ⚔️ **Воин / Рыцарь (Warrior)**:
     - 300 HP, скорость 195. Ближнебойный танк с тяжелыми латами и мечом.
     - Атака 1: *Быстрый взмах* (ЛКМ / Q) — рубящий удар мечом в секторе (урон 35).
     - Атака 2: *Круговой вихрь* (ПКМ / E) — 360° вихрь с отталкиванием (урон 70).
     - Атака 3: *Клинок ветра* (Пробел) — энергетический снаряд через 8 врагов (урон 110).
     - Рывок: *Рыцарский рывок* (Shift / F) — стремительный рывок сквозь ряды зомби.
  2. 🏹 **Стрелок / Лучник (Ranger)**:
     - 230 HP, скорость 218. Высокая мобильность, дальнобойный охотник с луком и колчаном.
     - Атака 1: *Выстрел стрелой* (ЛКМ / Q) — точный пронзающий выстрел (урон 45).
     - Атака 2: *Веер стрел* (ПКМ / E) — веерный выстрел 5 стрелами полукругом (урон 38).
     - Атака 3: *Разрывная стрела* (Пробел) — взрывная стрела с AoE уроном по площади (урон 120).
     - Рывок: *Кувырок следопыта* (Shift / F) — быстрый акробатический перекат с ускорением +10%.
  3. 🔮 **Маг / Архимаг (Mage)**:
     - 205 HP, скорость 190. Разрушительная магия стихий в лазурной мантии с посохом.
     - Атака 1: *Чародейская стрела* (ЛКМ / Q) — скоростной самонаводящийся снаряд тайной магии (урон 40).
     - Атака 2: *Огненный шар* (ПКМ / E) — мощный взрывной шар с огненным радиусом поражения (урон 85).
     - Атака 3: *Кольцо льда* (Пробел) — ледяная волна 360°, критический урон и замедление/заморозка толп на 3 сек (урон 95).
     - Рывок: *Скачок / Блинк* (Shift / F) — мгновенная пространственная телепортация вперед на 190 px.
  4. 💀 **Призыватель / Некромант (Summoner)**:
     - 245 HP, скорость 195. Повелитель душ в темном балахоне с костяным посохом.
     - Сопровождается **миньонами-скелетами** (до 4 активных), которые атакуют врагов и защищают хозяина.
     - Атака 1: *Хлыст душ* (ЛКМ / Q) — призрачный удар хлыстом, указывает цель миньонам (урон 35).
     - Атака 2: *Призыв миньонов* (ПКМ / E) — призыв скелетов-помощников в гущу битвы.
     - Атака 3: *Взрыв душ* (Пробел) — поток призрачных черепов (урон 110).
     - Рывок: *Шаг духа* (Shift / F) — бесплотное призрачное скольжение сквозь врагов.
- **Сохранение прогресса (`save_data.json`)**:
  - Автоматическое сохранение прогресса карьеры (души, рекорды, статистика).
  - Автосохранение чекпоинтов активного забега (класс выбранного героя, текущие HP, волна, счет, навыки).
  - Кнопка «Сохранить и выйти в меню» в меню паузы.
- **Поле боя**: Арена 50x50 клеток (1600x1600 пикселей) с каменными стенами и плиточным полом.
- **4 вида зомби с уникальным поведением**:
  - **Walker**: базовый зомби, средняя скорость и здоровье.
  - **Runner**: быстрый красный мутант, ускоряющийся при приближении к игроку.
  - **Spitter**: кислотный стрелок, держит дистанцию и стреляет ядовитыми плевками.
  - **Brute**: бронированный громила с высоким здоровьем, высоким уроном и сопротивлением отталкиванию.
- **Система уровней и улучшений во время забега (Roguelite)**:
  - Из поверженных зомби выпадают сферы опыта (XP), притягивающиеся магнитом героя.
  - При повышении уровня открывается окно с выбором 1 из 3 случайных карт улучшений.
- **Волновой режим выживания**:
  - Каждая следующая волна увеличивает число врагов, частоту спавна и силу орды.
  - Каждые 5 волн — опасная **Босс-волна** с ордой громил!
- **8-битный процедурный аудио-движок (Chiptune SFX)**:
  - Процедурный синтезатор ретро-звуков (взмахи меча, выстрел из лука, заклинания, взрывы, заморозка, телепортация, призыв нежити, удары по зомби, ранения, рывок, уровень, клики меню, звон улучшений, начало волны, game over) без внешних аудио-файлов.

## ⌨️ Управление

| Действие | Клавиатура и Мышь | Геймпад / Steam Deck |
|---|---|---|
| **Движение** | `W`, `A`, `S`, `D` или `Стрелки` | Левый стик / D-Pad |
| **Прицеливание** | Курсор мыши | Правый стик / Направление |
| **Навык 1 (Быстрый удар / выстрел)** | `ЛКМ`, `1`, `Q` | `RT`, `RB`, `A` |
| **Навык 2 (Вихрь / веер / фаербол / призыв)** | `ПКМ`, `2`, `E` | `LT`, `X` |
| **Навык 3 (Клинок / разрывная / мороз / черепа)** | `Пробел`, `3`, `R` | `Y` |
| **Рывок / Перекат / Телепорт** | `Shift` (левый/правый), `F` | `LB`, `B` |
| **Пауза** | `P`, `Esc` | `Start` |
| **Звук Вкл/Выкл** | `M` | `Select / View` |
| **Выбор улучшения** | `1`, `2`, `3` или Клик мыши | `A` (подтверждение) |
| **Полноэкранный режим**| `F11` | — |

## 🚀 Установка и запуск

1. Убедитесь, что установлен Python 3.10+ (рекомендуется Python 3.11 - 3.14).
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите игру:
   ```bash
   python main.py
   ```
   *(Также можно запускать через `python src/main.py`)*

## 📦 Сборка в автономное приложение (.exe)

Игра может быть скомпилирована в единый автономный исполняемый `.exe` файл для Windows, который запускается без необходимости устанавливать Python или зависимости:

1. **Готовый исполняемый файл**:
   - Находится в папке [`dist/KnightVsZombies.exe`](file:///c:/Users/Qadwer/.vscode/Projects/knight_zombies_game/dist/KnightVsZombies.exe).
   - Имеет встроенную кастомную иконку шлема рыцаря, графические ресурсы и оконный режим без консоли.
   - Запускается двойным кликом на любой Windows 10/11 x64.
   - Сохранения прогресса (`save_data.json`) автоматически ведутся рядом с файлом (портативный режим).

2. **Быстрая повторная сборка**:
   - Запустите скрипт [`build.bat`](file:///c:/Users/Qadwer/.vscode/Projects/knight_zombies_game/build.bat)
   - Или выполните в терминале:
     ```bash
     pyinstaller --noconfirm KnightVsZombies.spec
     ```

## 🧪 Запуск тестов

Для запуска набора тестов выполните:
```bash
python -m unittest discover -s tests
```
или через pytest:
```bash
pytest
```
Все **91 unit-тест** (и **104 теста в pytest**) проверяют:
- 4 класса персонажей (Воин, Стрелок, Маг, Призыватель): характеристики, способности, кулдауны и физика.
- Поведение всех снарядов (стрелы, взрывные стрелы, чародейские снаряды, огненные шары, волны душ, клинок ветра, плевки кислоты).
- ИИ миньонов-скелетов: преследование цели, атака врагов, следование за призывателем, получение урона, механика колосса.
- Заморозка и замедление зомби эффектом Кольца льда.
- Сохранение и загрузка прогресса, мета-прокачка героев, мастерства, чекпоинты с сохранением класса персонажа и настройки.
- ИИ зомби, архетипы, урон, алгоритмы сближения и награды душ.
- Балансировочные константы и централизованный конфиг `config.py` (персонажи, снаряды, зомби, экономика лагеря, формулы опыта и 45 улучшений).
- Полная симуляция игрового процесса, навигации по меню выбора класса, а также рендеринг всех экранов и всех процедурных иконок.

## ⚙️ Структура баланса игры (`src/config.py`)

Все игровые настройки и параметры баланса вынесены в структурированные классы в файле [`src/config.py`](file:///c:/Users/Qadwer/.vscode/Projects/knight_zombies_game/src/config.py):

1. **`DisplayConfig`**: Разрешение экрана (1280x720), целевой FPS (60), размеры арены (1600x1600 px), тайлов и палитра арены (`COLOR_BG`, `COLOR_BORDER`, `COLOR_TILE_A`, `COLOR_TILE_B`).
2. **`PlayerBaseBalance`**: Общие базовые параметры героев (радиус хитбокса, базовый откат и длительность рывка, регенерация, радиус сбора сфер).
3. **Классы героев**:
   - **`WarriorBalance`**: Здоровье (300), скорость (195), параметры способностей (взмах, круговой вихрь, клинок ветра, рывок `skill_dash`).
   - **`RangerBalance`**: Здоровье (230), скорость (218), параметры способностей (выстрел, веер из 5 стрел, разрывная стрела, кувырок `skill_roll`).
   - **`MageBalance`**: Здоровье (205), скорость (190), параметры способностей (чародейская стрела, фаербол, кольцо льда, телепортация `skill_teleport`).
   - **`SummonerBalance`**: Здоровье (245), скорость (195), лимит миньонов (4), параметры способностей (хлыст душ, призыв, взрыв душ, призрачный шаг `skill_ghost_step`).
4. **`MinionBalance`**: Базовые параметры скелетов (85 HP, 210 скорость, 22 урон) и множители исполина-колосса (2.2 HP, 2.0 урон, радиус 17 px).
5. **`ZombieWaveBalance` & `ZOMBIE_ARCHETYPES`**:
   - Прогрессия сложности волн: базовая задержка спавна (1.2 с -> мин. 0.35 с), прирост HP (+10% за волну), урона (+6% за волну), бонус на 5/10/15 волнах (+25% HP).
   - Характеристики 4 видов зомби: `walker` (65 HP, 1 душа), `runner` (40 HP, 2 души), `spitter` (60 HP, 2 души, ядовитый плевок), `brute` (240 HP, 5 душ).
6. **`ProjectileBalance`**: Скорость, дальность, урон, радиус и пронзание для снарядов всех классов и кислоты врагов.
7. **`EconomyBalance`**:
   - Опыт и уровни в забеге: базовый опыт 1-го уровня (100 XP), прирост требуемого опыта (+20% за уровень).
   - Сферы опыта (15 XP) и награда душ за волну (+2 души).
   - Постоянные улучшения Лагеря (Скорость +6%/ур, Здоровье +25/ур, Урон +8%/ур) с базовой стоимостью и множителями цен.
8. **`UpgradeBalance`**:
   - Вероятности выпадения редкостей карт (common/rare/epic) на разных стадиях волн.
   - Значения всех 5 уровней для 5 общих улучшений и 40 классовых улучшений.

## 📁 Структура проекта

```
knight_zombies_game/
├── dist/
│   └── KnightVsZombies.exe  # Автономное скомпилированное приложение
├── assets/
│   ├── app_icon.ico         # Иконка приложения Windows
│   ├── sprites/             # Спрайты и графические ассеты (knight_banner.png)
│   └── sounds/              # Звуковые ресурсы
├── src/
│   ├── audio/               # 8-битный синтезатор звуков (SoundEngine)
│   ├── entities/            # 4 класса героев, Зомби 4 типов, Миньоны, Снаряды, Сферы XP
│   ├── input/               # Обработка ввода (Клавиатура, Мышь, Геймпад)
│   ├── rendering/           # Отрисовка классов, мира, эффектов частиц, камера, виньетка, IconEngine
│   ├── ui/                  # HUD панель, меню с экраном выбора класса и подменю, модалки
│   ├── upgrades/            # База внутриигровых улучшений (UpgradeCard, UpgradeBalance)
│   ├── config.py            # Централизованный баланс игры, пути к ресурсам и сохранениям
│   ├── save_manager.py      # Менеджер сохранений (карьера, мета-прогресс, активный забег)
│   ├── game.py              # Основной менеджер игры и игровой цикл
│   └── main.py              # Входная точка в src/
├── tests/                   # Набор модульных тестов (91 unit-тест / 104 в pytest)
├── build.bat                # Скрипт сборки в 1 клик
├── KnightVsZombies.spec     # Конфигурация сборки PyInstaller
├── requirements.txt         # Зависимости
├── main.py                  # Главная точка входа
└── README.md                # Документация проекта
```
